# SmartLab: Virtual Science Lab

A next-gen, AI-driven, web-based science laboratory for Pakistani school students (Physics & Chemistry, Federal Board).

## 📁 Project Structure
- frontend/  (Next.js, 3D + Animations)
- backend/   (FastAPI, PostgreSQL, ML/AI)
- datasets/  (Experiment, ML data)
- docs/      (Research, design, setup instructions)
- scripts/   (Dev tools)

## 🚀 Tech Stack
- **Frontend:** Next.js (React), TypeScript, Three.js, TailwindCSS, Framer Motion, Chart.js, Konva.js
- **Backend:** FastAPI (Python), PostgreSQL, Docker, AI/ML (HuggingFace/Colab)

## ⚡ Getting Started
1. Install Node.js, Python 3.10+, Docker.
2. `cd frontend` — `npm install` — `npm run dev`
3. `cd backend` — activate venv — `pip install -r requirements.txt` — `uvicorn main:app --reload`
4. Visit frontend: [http://localhost:3000](http://localhost:3000)
5. Visit backend: [http://localhost:8000](http://localhost:8000)
